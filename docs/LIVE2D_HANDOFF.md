## 本轮已制作·待实机确认

以下项目在 v0.3.0 制作，仍需继续观察：

1. 迷梦默认头部触摸区域，以及双点校准头部区域。
2. 在头部区域连续滑动触发摸头；摸头期间眼睛保留跟随，头部跟随降权，身体跟随大幅降权。
3. 普通摸头为闭眼、笑眼、脸红、轻微低头蹭动。
4. 每次摸头独立以 1/10 概率触发疑惑彩蛋；概率效果尚未单独确认。
5. LLM 返回 `none` 时依据情绪补充自然反应的长期观感。

## v0.3.1 已制作·待实机确认

1. 摸头双点校准不是正方形约束；最小归一化宽度由 12% 降到 8%，最小高度由 12% 减半到 6%，允许只框头顶窄条。
2. `wind_sway_soft`、`wind_sway_medium`、`wind_sway_showcase`、`showcase_orbit` 保持身体摆动、头部位置和动作路线不变。
3. 上述四个动作只在 physics 之后限制最终 `ParamAngleX` 脸部左右转向，使侧脸接近“跟随：标准”的范围。

## v0.3.2 已实机确认

1. 11 种程序情绪保留原有设计，脸部参数相对中性值放大至 1.65 倍，附带头部姿态放大至 1.3 倍；`neutral` 仍保持中性，不修改 ZIP 自带表情。
2. ZIP 外观／部件不再通过单一 Cubism expression 互相替换，改为独立的持久开关，允许发型、衣服、饰品和道具同时叠加。
3. 一个 `.exp3.json` 内的原作者组合保持为一个开关整体应用。例如“双马尾”仍同时设置 `Param66` 后发消失与 `Param72` 双马尾。
4. 外观按钮显示开启状态，支持逐项关闭和全部还原；开启状态保存在 App 本地，并在舞台重新载入后恢复。

## v0.4.0 已制作·待实机确认目标

以下内容先登记为本轮制作目标；完成构建后仍必须由用户真机确认：

1. Sen Customizable Model 2K 专属 ModelProfile；标准 `ParamAngleX/Y/Z` 作为程序姿态和触屏跟随输入，`ParamAngleX2/Y2/Z2` 仅视作作者物理输出。
2. 保留原始 2K 贴图，并在首次导入时自动生成可切换的 1K 流畅副本；默认优先 1K，避免 26 张 2K RGBA 贴图造成约 416 MiB 的基础纹理显存压力。
3. 页面固定为上方约 2/3 模型预览、下方约 1/3 不透明测试面板；聊天框改为按需显示，不再长期占据模型预览区。
4. 自动登记 Sen 的 15 个 exp3 文件，但普通测试面板只显示 13 个用户内容：9 个脸部／效果预设和 4 个道具／状态预设；`Watermark` 不允许作为 AI/普通测试开关，`press` 保留为系统交互预设。
5. 将 `daiji.motion3.json` 作为特效支撑循环；将 `keyboard/` 下 36 个按键 motion 单列测试，不把它们误当作全身待机动作。
6. 显示导入诊断：模型档案、moc3 体积、贴图数量/最大尺寸/估算 RGBA 显存、预设与动作数量、当前 1K/2K 模式和舞台加载耗时。
7. 保留已确认的 26 个程序参数动作、11 种程序情绪、触屏跟随、摸头、API 对话和模型位置缩放，先用于验证 Sen 的参数与物理兼容性。

## Sen Customizable Model 2K 预分析（代码制作前）

- 模型 moc3 约 139.2 MiB，MOC3 版本字节为 5；共有 26 张 2048×2048 RGBA 贴图。
- CDI3 约有 581 个参数、268 个部件和 30 个参数分组，属于高精度可换装模型；约 244 个参数位于作者可调整区。
- physics3 有 76 组物理：标准 `ParamAngleX/Y/Z` 被大量读取，`ParamAngleX2/Y2/Z2` 是物理输出。此处不能复用迷梦的参数别名顺序。
- 15 个 exp3：9 个脸部／效果（Blush、Dizzy eyes、Heart eyes1/2、Shocked、Starry eyes、Sulking、Teary eyes、Weepy eyes），4 个道具／状态（Controller、Keyboard & Mouse、Microphone、Loading），以及 Watermark、press 两个系统用途预设。
- 37 个 motion3：`daiji` 是 4 秒循环的特效参数动画；另外 36 个是键盘按键短循环。没有作者提供的完整全身情绪动作，因此现有程序动作仍有价值。
- model3 没有作者 HitAreas，摸头继续使用归一化区域与用户校准。

## 迷梦模型的关键细节

### 参数与物理

- 优先头部输入：`ParamAngleX2`、`ParamAngleY2`、`ParamAngleZ2`。
- `X2/Y2/Z2` 是迷梦大量物理设置的输入；在 motion 后、physics 前写入，头发、衣服和饰品才能消费本帧姿态。
- 普通 `ParamAngleX/Y/Z` 更接近物理输出/标准角度，不应作为迷梦的第一选择。
- `ParamBodyAngleX/Z` 可以承担明显摆动。
- `ParamBodyAngleY` 曾造成身体拉扁，语义安全范围维持 `[-1.2, 1.2]`，触屏实际增益更低。
- 所有值仍需同时接受模型 moc3 自己声明的 min/max 限制。

### 模型资源

- 迷梦 ZIP 没有 `.motion3.json`，因此当前成套动作是程序参数关键帧，不是作者原生动画。
- 迷梦有大量 `.exp3.json`，其中混有表情、换装、部件显示/隐藏，不能仅凭扩展名都当作面部表情。
- 迷梦当前包有 38 个 `.exp3.json`：按名称和 CDI 参数核对为 3 个表情、35 个外观／部件；所有引用参数均存在。
- 原包的 VTube Studio 配置使用 `ToggleExpression`，允许多个外观同时启用；App 不能用单一 expression manager 代替这种叠加状态。
- `model3.json` 没有 `HitAreas`，不能依赖作者提供的头部点击区域；需要默认区域或用户校准。
- 已知缺少：爱心眼、星星眼、圈圈眼、完整哭泣表情。

## 表演层叠加顺序

从基础到高优先级：

1. 情绪基础表情与平滑过渡。
2. 呼吸、微动和随机注视。
3. 触屏视线与头身跟随。
4. 情绪相关随机待机动作。
5. LLM / 对话阶段动作。
6. 触摸互动动作（摸头等）。
7. 语义安全限幅与 moc3 声明范围。

摸头时不能让两套头部控制全功率叠加：眼睛保持跟随，头部跟随约 25%，身体跟随约 15%，摸头关键帧作为高优先层。

## 24 个动作的推荐职责

| 类别 | 动作 |
| --- | --- |
| 中性待机 | `small_nod`, `head_tilt_idle`, `side_look`, `weight_shift`, `gentle_lean`, `slow_blink`, `look_around`, `soft_sway`, `wind_sway_soft` |
| 赞同/确认 | `nod`, `small_nod` |
| 拒绝/不满 | `shake_head`, `pout` |
| 好奇/疑惑 | `tilt_head`, `head_tilt_idle`, `side_look`, `look_down_up`, `gentle_lean` |
| 吃惊/退缩 | `blink_surprised`, `lean_back` |
| 难过/疲惫 | `sigh`, `sigh_sink`, `slow_blink` |
| 开心/庆祝 | `excited_bounce`, `nod`, `wind_sway_medium` |
| 倾听/靠近 | `listening`, `lean_forward`, `gentle_lean` |
| 低频展示 | `wind_sway_showcase`, `showcase_orbit` |

不要把 `shake_head`、`sigh`、`pout`、`blink_surprised` 无条件放进中性随机池，否则角色会无缘无故拒绝、难过或受惊。

## 更换模型检查清单

1. 找到 `.model3.json`、moc3、纹理、physics3、cdi3、exp3、motion3。
2. 检查是否有标准 `ParamAngleX/Y/Z`，以及类似迷梦的二级物理输入。
3. 用 CDI3 名称辅助理解参数，但不能只相信参数 ID。
4. 逐个测试 body X/Y/Z；一旦发现压扁，立即降低或禁用对应通道。
5. 检查 `HitAreas`；没有时设置归一化触摸区域并允许用户校准。
6. 区分面部表情、换装、道具和部件开关。
7. 所有新映射先标记“待实机确认”。
8. 真机确认后，把结果写回本文档和对应 `model-profiles/*.json`。
